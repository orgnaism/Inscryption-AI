# Worked examples

**Provenance.** Everything in the result blocks below was produced by running this
repository's code on 2026-10-24 (Python 3.13, Windows). Artwork was **not** generated by
FLUX in these runs: `--dry-run` uses the built-in placeholder portrait, so the images
only show layout. Nothing here was run inside Inscryption.

- The **pinecone** input is the JSON from the project brief (`examples/pinecone.json`).
- The **raven** input (`examples/raven.json`) was **written by hand** to look like analyzer
  output. It is an illustrative input, not a real camera scan.

Full output folders: `inscryption_card_generator_flux2_klein_4b/inscryption_card_generator_flux2_klein_4b/examples/act1_pinecone/` and `.../examples/act1_raven/`.

## 1. Pinecone (non-animal)

```bash
python generate_card.py --analysis examples/pinecone.json --dry-run --explain \
  --output-dir examples/act1_pinecone --jsonloader-dir examples/act1_pinecone/jsonloader_alternative
```

### Input

```json
{
  "object_name": "pinecone",
  "dominant_material": "organic",
  "secondary_materials": ["wood"],
  "textures": ["rough", "ridged", "sharp"],
  "hardness": "hard",
  "flexibility": "rigid",
  "size": "small",
  "shape": "irregular",
  "reflective": false,
  "sharp": true,
  "organic": true,
  "electronic": false,
  "confidence": "high"
}
```

### How each property was interpreted (program output, `--explain`)

```
size: small: sets the baseline (health 2); never sets cost by itself
hardness: hard: toughness evidence
dominant_material: organic: toughness evidence (overlaps hardness; strongest one wins)
secondary_materials: ['wood']: weaker supplementary toughness evidence
toughness: level 2 from ['hardness=hard'] -> +1 health
flexibility: rigid: secondary; no direct stat effect
sharp: True: sharpness evidence is strong
natural_weapon: sharpness on a non-animal (or an animal without natural weapons) is not a weapon
passive_spines: rigid sharp surface on a non-animal -> eligible for Sharp Quills, no attack bonus
textures: ['rough', 'ridged', 'sharp']: used only as corroboration (sharpness, protective structure), never alone
shape: irregular: only matters for blade-like objects and tall structures
reflective: False: descriptive surface evidence only; no stat effect
organic: True: used to tell living subjects from objects and depictions
electronic: False: electronic subjects become plain object cards; Act 1 has no energy or technology sigils
confidence: high reported, high after checks
stats: health 2 from size=small
stats: attack 0: plant subjects do not hunt
stats: +1 health: toughness level 2 from ['hardness=hard']
stats: estimate: 0/3
```

### Decisions

| Question | Result | Why |
|---|---|---|
| Animal? | **No**: kind `plant` | `pinecone` matches the taxonomy's plant entry. No animal traits are attached (`identification.traits == []`). |
| Tribe | **Miscellaneous** → no game tribe (`tribes: []`) | Non-animal subjects never get an animal tribe; "no tribe" is how the game represents it. |
| Attack | **0** | Plants do not hunt. Its sharpness is *passive*: it is not blade-shaped (irregular), so it is not an edge. |
| Health | **3** | small = 2, plus toughness level 2 from `hardness=hard` = +1. `organic`/`wood` are weaker, overlapping evidence, so they do not stack. |
| Sigils | **Sharp Quills** (`Sharp`, power 2) | Physical rule *passive_spines*: `sharp=true` and texture "sharp" agree, it is hard and rigid, and it is not a blade. The scales hurt whatever strikes it, with no invented claws or teeth. Nothing else was eligible. |
| Card Power | **5** = 0×2 + 3 + 2 | |
| Blood cost | **1** | CP 5 fits the 1-blood band (≤ 6), not free (> 3). Vanilla 1-blood commons span CP 3–6. Compare Porcupine 1/2 Sharp Quills (CP 6) and Skunk 0/3 Stinky (CP 5). |
| Name / description | **Pinecone** / "A pinecone from beyond the cabin. Strike it and bleed." | Real-object name (variant 2 uses "Strobilus", the botanical term, following the guide's taste for uncommon names). |

## 2. Raven (animal, hand-written input)

```bash
python generate_card.py --analysis examples/raven.json --dry-run --explain --output-dir examples/act1_raven
```

Input: `object_name: "raven"`, organic, soft, semi-flexible, **medium**, smooth/glossy,
reflective, not sharp, high confidence, `visible_features: ["feathers", "wings", "beak"]`.

```
[variant 1] Raven | Avian | 1/3 | 2 blood | Airborne, Scavenger | valid
    size: medium: sets the baseline (health 3, attack 1); never sets cost by itself
    toughness: level 0 from ['no hard materials'] -> +0 health
    sharp: False: sharpness evidence is none
    reflective: True: descriptive surface evidence only; no stat effect
    stats: health 3 from size=medium
    stats: attack 1 from size=medium (animal baseline)
    stats: estimate: 1/3
```

| Question | Result | Why |
|---|---|---|
| Animal? | **Yes** | Taxonomy entry `raven` has traits `flight` and `scavenger`. |
| Tribe | **Avian** → `Tribe.Bird` | |
| Stats | **1/3** | Medium animal baseline. No natural weapon (ravens have none in the taxonomy) and not a predator. `reflective` has no effect. |
| Sigils | **Airborne** (0) + **Scavenger** (2) | Airborne is the Avian signature (trait `flight`). Scavenger comes from trait `scavenger`. High confidence allows 2. |
| CP / cost | **7 → 2 blood** | Same CP and cost as the vanilla Raven (2/3 Airborne). The Airborne cap allows attack ≤ 2 at 2 blood. |
| Description | "The Raven. It profits from every death." | |

Registration (`variant_1_registration.cs.txt`):

```csharp
CardInfo info = CardManager.New("ScannedCards", "raven_41830e1d", "Raven", 1, 3, "The Raven. It profits from every death.");
info.SetBloodCost(2);
info.SetDefaultPart1Card();  // ChoiceNode + TraderOffer, CardTemple.Nature
info.AddAbilities(Ability.Flying, Ability.OpponentBones);
info.AddTribes(Tribe.Bird);
info.SetPortrait(TextureHelper.GetImageAsTexture(Path.Combine(cardsDir, "raven_41830e1d.png")));  // 114x94
```

With `confidence: "medium"` the same raven gets only Airborne. With `"low"` it becomes a
tribeless, sigil-less conservative card and a rescan is recommended (see `tests/test_sigils.py`).

Notes:

- The rattlesnake is **adjusted**: Touch of Death sets attack to 1, as on vanilla Adder.
- "a dog and a cat": the first-named animal is the subject. The two tribes conflict, so
  confidence drops from high to medium and only 1 sigil is allowed.
- The contradictory turtle: 3 contradictions plus missing size/shape/sharp. Confidence
  drops to medium, and missing values are treated as unknown, not false.
